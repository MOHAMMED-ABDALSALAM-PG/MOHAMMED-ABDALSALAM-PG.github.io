# Academic website — Mohammed Alfatih Osman Abdalsalam

Source of <https://mohammed-abdalsalam-pg.github.io>.

A small static site generated with Python (standard library only) from structured data, deployed to GitHub Pages by GitHub Actions.

## Layout

```
data/profile.json        biography, education, experience, skills (source: CV of 18 Nov 2026)
data/publications.json   verified publication records: authors, venue, DOI, links, status, summary, verification source
data/projects.json       curated manifest of repositories shown on the site (nothing else is ever listed)
data/resources.json      datasets and models, with their real availability
data/github.json         public repository metadata (generated by scripts/fetch_github.py)
build.py                 renders dist/ (pages, charts as inline SVG, sitemap, publications.json)
scripts/fetch_github.py  refreshes public metadata for repositories in the manifest; skips private ones
scripts/check_site.py    privacy checks (phone numbers, e-mails, secrets) and link checks
scripts/make_profile_readme.py  writes the GitHub profile README from the same data
assets/                  CSS, JavaScript, images
```

## Updating

- **New paper:** add an entry to `data/publications.json` (verify the DOI on Crossref first), push. Move accepted papers to `publications` only once they are formally published.
- **New project:** add the repository to `data/projects.json`. Only public repositories are rendered.
- **Profile README:** `python3 scripts/make_profile_readme.py > ../MOHAMMED-ABDALSALAM-PG/README.md`.

Local preview:

```bash
python3 build.py && python3 scripts/check_site.py && python3 -m http.server -d dist 8000
```

## Automation

`.github/workflows/deploy.yml` builds and deploys on every push and once a week. The weekly run refreshes stars, last-push dates and licences of the curated repositories and runs an external link check (report only). The workflow has read-only repository permissions; only the deploy job can write to Pages.

## Content policy

Every chart is drawn from the data files above; diagrams marked *conceptual* are not data. Contact information is limited to the institutional e-mail address.
